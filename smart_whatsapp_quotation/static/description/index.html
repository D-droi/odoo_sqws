📲 Smart WhatsApp Quotation Sender

Send your sales quotations to customers directly via WhatsApp Web — including the PDF document and a customizable message — all without using any third-party API or requiring WhatsApp Business approval.

✨ Features

  • 🟢 Adds "Send via WhatsApp" button on Quotation form
  • 📎 Automatically attaches the actual PDF (not just a link)
  • ✏️ Supports dynamic message templates with placeholders like {customer_name} and {pdf_url}
  • 🌍 International phone number formatting (TR, UK, UAE, etc.)
  • 🧩 Fully compatible with custom quotation reports
  • 🛠️ Configurable default template via Settings → General Settings
  • 📜 Audit trail with WhatsApp message history per quotation

⚙️ Setup Instructions

  1. Copy the smart_whatsapp_quotation folder into your Odoo addons/ directory.
  2. Restart your Odoo server.
  3. Activate Developer Mode.
  4. Go to Apps → Update Apps List.
  5. Search for Smart WhatsApp Quotation Sender and click Install.

💡 Notes

  • 🧠 If the customer has no phone number on file, the WhatsApp window will not open.
  • 🔗 The PDF is sent via a public link that opens the exact quotation document.
  • 📝 The module automatically detects and uses your custom report template (if defined).
